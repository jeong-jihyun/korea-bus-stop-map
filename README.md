# 버스 정류장 찾기

버스 번호를 입력하면, 내 주변(또는 지도에서 클릭한 곳)에서 그 버스가 서는 정류장을 지도에 표시합니다.

## 실행

```bash
node server.js          # Node 18 이상
# 브라우저에서 http://localhost:3000
```

인증키가 없으면 **데모 모드**(샘플 정류장)로 동작합니다.

## 실제 데이터 쓰기

1. [공공데이터포털](https://www.data.go.kr)에서 아래 두 API를 활용신청 (무료)
   - 국토교통부_(TAGO)_버스노선정보
   - 국토교통부_(TAGO)_버스정류소정보
2. `.env.example` 을 `.env` 로 복사하고 `TAGO_API_KEY=` 뒤에 키 입력
3. `node server.js` 다시 실행

## 동작 순서

1. 내 위치 근처 정류장 조회 → 어느 도시인지(cityCode) 알아냄
2. 그 도시에서 버스 번호로 노선 조회
3. 노선이 지나는 정류장 중 반경 안의 것만 골라 가까운 순으로 표시

## 파일

- `server.js` : 공공데이터 API 호출 + 결과 정리 (키를 브라우저에 노출하지 않음)
- `public/index.html` : 화면 (Leaflet + OpenStreetMap 지도)

## 참고

- 같은 번호의 노선이 여러 개면(마을버스 등) 최대 6개까지 합쳐서 보여줍니다.
- 위치 권한은 https 또는 localhost 에서만 동작합니다.

## 점검 기록 (2026-10)
| 항목 | 결과 |
| --- | --- |
| `server.js`, 화면 안의 스크립트 문법 | 통과 |
| 데모 모드 (`/api/search`) 응답, 필수값 누락 시 400, `/` 200, 상위 폴더 접근(`/../server.js`) 404 | 정상 |

| 실제 공공데이터포털 호출, 브라우저 지도 표시 | **미확인** (이 환경에서 data.go.kr에 접속할 수 없고 화면이 없음) |

## 사용 방법

- **버스 번호로 찾기**: 번호를 입력하고 "찾기" → 그 버스가 서는 정류장이 지도에 표시돼요.
- **버스 번호를 모를 때**: "주변 버스 보기" → 내 주변 정류장과 각 정류장에 서는 버스 번호가 나와요. 번호를 누르면 그 버스의 정류장을 바로 보여줘요.
- 서울 등 일부 지역은 공공 데이터(TAGO)에 정류장이 없을 수 있어요.
- **지역 선택**: 맨 왼쪽 칸에서 "내 주변" / "전국 전체" / 도시를 고를 수 있어요. 도시나 "전국 전체"를 고르면 위치와 상관없이 그 번호의 노선 목록이 나오고, 노선을 누르면 전체 정류장이 순서대로 지도에 그려져요.
- "전국 전체"는 도시 수만큼(수십 번) 공공데이터를 호출해요. 개발계정은 하루 10,000번이라, 같은 검색은 1시간 동안 저장해서 호출을 줄여요.
